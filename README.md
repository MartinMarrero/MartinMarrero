Este fue el primer programa que hice cuando comencé la carrera:

```c++
#include <iostream>

int main() {
    std::cout << "Hello, world!" << std::endl;
    return 0;
}
```

Más adelante, fui desarrollando mis habilidades de programación hasta poder realizar programas más complejos, desde resolver ecuaciones de primer grado, como puede ser `2x + 4 = 0`, a programar auténticos Autómatas Finitos Regulares (DFAs), simuladores celulares, generadores de gramáticas, entre muchos otros.

A día de hoy, tengo la capacidad de programar aplicaciones de escritorio mucho más complejas. Por ejemplo, actualmente estoy desarrollando, junto con un compañero, un simulador de una máquina RAM. :sweat_smile:

Las asignaturas que más me han gustado hasta ahora en la carrera son:
* Expresión Gráfica en Ingeniería
* Algoritmos y Estructuras de Datos
* Inteligencia Artificial
* Inteligencia Artificial Avanzada
* Inglés Técnico

A lo largo de la carrera, aprendí a utilizar los siguientes lenguajes de programación:
1. C++
2. Ensamblador
3. Ruby
4. R
5. JavaScript / TypeScript
6. Verilog / VHDL
7. Bash
